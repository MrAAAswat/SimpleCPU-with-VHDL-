# SimpleCPU-with-VHDL-
Focuses on designing a simple 4-stage pipelined CPU on an FPGA capable of executing basic arithmetic and logic operations. The CPU includes a small register file with four 8-bit registers and uses RS and RT fields to select source and destination operands.


The lab8 details using a finite-state machine solution whereas lab9 includes pipelining with consecutive instructions. VHDL program can be viewed on the documents as well as some other details.
